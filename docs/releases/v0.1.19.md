## Fixed

A follow-up to v0.1.18, after an independent review of everything changed
since v0.1.15 turned up gaps in the blank-popup fix and the download-list save.
Nothing here is a new feature; all of it is making the fixes in v0.1.16–v0.1.18
hold up in the cases the review found.

**A popup opened a second time could still come up blank.** ([#10](https://github.com/ahmadfarooqofficial/Fast-Download-Manager/issues/10))
If you closed a download's popup and opened it again by double-clicking the row,
FDM still remembered that the first one had loaded and would not watch the
second. Each popup is now watched on its own.

**"Loaded" now means the popup is really running.** Windows reports a page as
finished loading even when the load failed. A popup now counts as live only
once its own script has reported in, which is the one signal that cannot be
faked by a failed load.

**Popups queued during startup are opened more carefully.** They used to be
created from inside the main window's own load event, which is exactly the kind
of moment a new window can come up blank. They are now opened just after it.

**A one-off hiccup no longer closes a fresh popup.** If the app could not be
asked about the download at the instant a popup opened, the popup closed itself
as though the download were gone. It now waits for a definite answer.

**The download list recovers from an interrupted save.** If FDM is killed in
the middle of the fallback write added in v0.1.18, the complete copy it was
about to put in place is picked up on the next start instead of the list
starting empty.

**Saves give up sooner when the file really cannot be written**, so a list that
is permanently unwritable cannot make every click feel slow.

**The issue greeter** now looks up the newest release instead of relying on a
hand-updated version, and no longer matches on single generic words such as
"category" or "connections".

## Known limitations

- Not code-signed, so Windows shows an "unknown publisher" warning on install.
  Click **More info → Run anyway**.
- The browser extension is not on the Chrome Web Store yet, so Chrome will ask
  you to enable it once after installing.
- The installer is available in 8 languages; the app itself has 12.
