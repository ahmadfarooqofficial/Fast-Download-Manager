## Fixed

**Two FDM icons in the tray, one of them dead.** ([#4](https://github.com/ahmadfarooqofficial/Fast-Download-Manager/issues/4))
The tray icon was being created twice: once from the app's configuration, before
any of the code that gives it a menu and a click handler had run, and once by that
code. The first one looked identical and answered to nothing. There is one now,
and it has a tooltip.

**A "ghost" icon left behind after launching FDM a second time.**
Double-clicking the shortcut while FDM was already sitting in the tray started a
second copy, which noticed the first and quit — but it had already registered a
tray icon of its own, and quitting that abruptly never removes one. Windows kept
drawing the dead icon until the mouse passed over it. The second copy now checks
for the first before it draws anything, and instead of a stray icon you get the
running FDM's window brought to the front — which is what the double-click was
for.

## Known limitations

- Not code-signed, so Windows shows an "unknown publisher" warning on install.
  Click **More info → Run anyway**.
- The browser extension is not on the Chrome Web Store yet, so Chrome will ask
  you to enable it once after installing.
- The installer is available in 8 languages; the app itself has 12.
